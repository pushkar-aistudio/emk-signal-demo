Beat 4b — Builds the profile new

"It searches relevant third-party databases and the web to enrich company information."

PILOT v3, per Pushkar's second fix-round: v2 still left the window "half black" — a gap of real background above/below/beside the real content — and a sliver of the app's real sidebar tab on the left. Root causes: (1) the page's main content column is a `<main class="overflow-auto">` clipped to the viewport, so Lead Intelligence and the services table existed in the DOM but weren't paintable past the fold — freed that container (overflow:visible, height:auto) so the real content the camera needs is actually there to show. (2) Measured the real, fixed real-estate precisely: header card x304-1537 (w1233) y145-481.5; page content worth showing runs y12 (top bar) to y884 (last table row) = h872. That box's own aspect ratio (1233/872) is almost exactly the window's (1040/740) — meaning one frame, scaled to overshoot both dimensions very slightly (0.86x, cropping a few px off the outermost edges rather than ever leaving a gap), fills the window completely: full card width, no sidebar, no background showing anywhere, top bar through the services table. There is no real slack left in that box for a zoom or pan without breaking one of those two constraints again, so this beat now runs one static, fully-covering frame — the motion is the field reveal (links, match-reason, description, stats fading in in place), not the camera. Still drives the actual app/apps/web dev server in demo mode (VITE_DEMO_MODE=true fixture data, no network) at localhost:5174/signal/leads/company/7001 — Viridea Logistica's real Company Details page. Fields are the real DOM nodes, hidden then un-hidden in place. Standing fixes from earlier rounds: demo-mode auth's React StrictMode race (skipped only under VITE_DEMO_MODE=true) so the real page renders at all, and the clip trimmed to start already composited (no raw-page flash). One deviation from the brief stands: the real page's match-reason row sits right after the links row (before description/stats), not "under the stats" — followed the real layout rather than forcing the assumed order.
