## Bugs found and fixed this pass (see `docs/OVERNIGHT-LOG.md` for full detail)

1. **`zoomRegion` used `transform-origin` math**, which is element-local — invisible on the
   app's viewport-aligned `#root`, but wrong by a full `scrollY` on the Command Centre's
   document-flow wrapper. All three SCC crops landed on the wrong block. Rewritten as
   translate+scale from a measured, untransformed origin — works for any element at any
   scroll position.
2. **Beat-2/end-card logo 404'd** — the `src` resolved relative to the current *route*
   (`/signal/actions/...`) instead of the app root. Fixed to `location.origin + '/emk-signal-logo.svg'`.
3. **Beat-4 dialog label never appeared** — `rectOf`'s text search scopes to `#root` by
   default; the Radix dialog portals to `document.body`, outside it, so the query silently
   returned null and the whole label branch was skipped. Fixed by scoping the query to
   `[role="dialog"]`.
4. **Once visible, the label had only 0.29s of dwell** before the scheduled cut fired —
   diagnosed by instrumenting real elapsed time inside the beat (not guessed): dialog-open
   overhead alone consumed 1.46s of a 4.32s beat. Trimmed the cursor-move and settle waits,
   moved the cut trigger to 2.0s.
5. **The label also sat on dimmed data** (the stats row), violating "never over a row,
   field or data". Fixed by widening the crop's bottom margin so the label docks in real
   empty space below the card.
